# UNIPARC

A culture-first lifestyle destination for people who are more than one thing.

## Stack
- Semantic HTML
- CSS (responsive, custom design system)
- Vanilla JavaScript
- No framework, build step, or runtime dependencies

## Local preview
Open `index.html` in a browser or serve this folder with any static HTTP server.

## Deploy
The project is static-hosting ready. Point Cloudflare Pages at this repository with:
- Build command: none
- Build output directory: `/`

## Notes
- Images are currently served from Unsplash's image CDN.
- Contact links use `hello@uniparc.in`; confirm the mailbox exists before publishing contact campaigns.
- The world filters and mobile navigation are client-side interactions.
