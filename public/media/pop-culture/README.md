# UNIPARC intro footage slots

The cinematic intro supports six replaceable, **muted** video panels. Add locally hosted MP4 clips in this directory using these exact filenames:

1. `anime-action.mp4`
2. `movie-moment.mp4`
3. `music-video.mp4`
4. `meme-reaction.mp4`
5. `anime-impact.mp4`
6. `cinema-trailer.mp4`

## Recommended clip specifications

- H.264 video in an MP4 container for broad browser support
- 16:9 landscape, ideally 1280×720 or 1920×1080
- 24–30 fps; short 2–5 second seamless or clean-cut loops
- Keep each file reasonably compressed (target 2–5 MB per clip)
- Remove audio tracks before adding footage; playback is muted in the intro regardless
- Use footage that UNIPARC owns, has licensed, or has permission to use

The panels start with shader-driven motion-design placeholders. When a video file loads, its footage replaces the procedural visual in that panel. If a file is missing or cannot play, the motion-design placeholder remains visible.

Do not commit copyrighted anime, movie, music-video, or meme footage unless the necessary rights have been cleared.
